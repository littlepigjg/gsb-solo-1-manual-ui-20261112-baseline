- 四个内置程序化蒙版的初始化、幂等、确定性 ID 与文件服务；重启后 ID 与目录默认值一致。
- 蒙版上传往返、缩略图、非法文件拒绝、内置蒙版删除拒绝、自定义蒙版删除及预设引用保护。

- 蒙版尺寸不匹配返回 400 `mask_size_mismatch` 且素材总数不增加；非法蒙版 ID、覆盖依据、越界强度/柔化、非色彩类嵌套操作、未知操作、嵌套参数越界、不存在的 ID 全部被拒绝，均不产生半成品。

- 目录默认蒙版 ID 与 `builtin_id("radial")` 钉死，嵌套白名单等于全部色彩调整操作。

## HTTP 端到端冒烟

以真实 Waitress 服务验证：上传带透明角的图片与同尺寸圆形蒙版 → 预览 PNG → 覆盖范围灰度图（中心覆盖、角落 0）→ 保存副本，中心按 factor 2.0 提亮、角落像素不变、Alpha 不变、来源参数完整 → 小尺寸蒙版被拒绝且无新副本。重启服务后内置与已导入蒙版均保留。
